Obmedzenia stĺpca — čo stráži a ako sa zapíše

ObmedzenieČo strážiPríklad zápisu
NOT NULLHodnota musí byť vyplnenámeno VARCHAR(100) NOT NULL
PRIMARY KEYJednoznačná identifikácia riadku (1×, nesmie byť NULL)id INT PRIMARY KEY
AUTO_INCREMENTDatabáza čísluje id sama (1, 2, 3…)id INT AUTO_INCREMENT PRIMARY KEY
UNIQUEŽiadne dve rovnaké hodnoty (NULL sa smie opakovať)email VARCHAR(100) UNIQUE
UNSIGNEDLen nezáporné čísla (a väčší kladný rozsah)id INT UNSIGNED
CHECK (rozsah)Dovolené len hodnoty spĺňajúce podmienkucena DECIMAL(8,2) CHECK (cena >= 0)
CHECK (zoznam)Dovolené len vymenované hodnoty (ako výber v Exceli)stav VARCHAR(30) CHECK (stav IN ('nová','zaplatená'))
FOREIGN KEYOdkaz musí smerovať na existujúci riadok inej tabuľkyFOREIGN KEY (zakaznik_id) REFERENCES zakaznik(id)

Pamätaj

Pravidlo
Rodičovské tabuľky vytváraj pred deťmi (FK musí mať na čo ukázať).
Typ FK = typ PK, na ktorý ukazuje (aj UNSIGNED!), inak FK neprejde.
Peniaze vždy DECIMAL, nikdy FLOAT.
AUTO_INCREMENT pre umelé id; reálne číslo (faktúra) zadávaš sám.
Celú definíciu overíš: SHOW CREATE TABLE nazov;

Celá tabuľka so všetkými obmedzeniami

CREATE TABLE faktura ( id INT UNSIGNED PRIMARY KEY, -- nezáporné, zadávame sami datum DATE NOT NULL, stav VARCHAR(30) NOT NULL CHECK (stav IN ('čaká na zaplatenie', 'zaplatená', 'stornovaná')), zakaznik_id INT NOT NULL, FOREIGN KEY (zakaznik_id) REFERENCES zakaznik(id) );
